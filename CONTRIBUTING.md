# Contributing to g-downloader

First off, thank you for considering contributing to g-downloader! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

## Setting up your development environment

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/salauddinn/g-downloader.git
   ```
3. Open Google Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode** in the top right corner.
5. Click **Load unpacked** and select the directory where you cloned the repository.
6. As you make changes to the code, click the **Refresh** icon on the extension card in `chrome://extensions/` to reload it.

## Making Changes

- Create a new branch from `main` for your work.
- Make your changes! Ensure that your code follows the existing style and conventions.
- Test your changes locally in Chrome to ensure everything works as expected.

## Submitting a Pull Request

1. Commit your changes and push them to your fork.
2. Open a Pull Request from your fork to the original repository.
3. Fill out the Pull Request template provided. Be sure to describe what your PR does and any issues it closes.
4. Wait for a review! We'll do our best to review your PR as quickly as possible.
