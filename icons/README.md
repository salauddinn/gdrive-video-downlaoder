# Extension Icons

This folder should contain three PNG icon files for the Chrome extension:

- **icon16.png** - 16x16 pixels (for the toolbar)
- **icon48.png** - 48x48 pixels (for the extension management page)
- **icon128.png** - 128x128 pixels (for the Chrome Web Store)

## Quick Method: Use the Icon Generator

**EASIEST OPTION:**

1. Open `generate-icons.html` in your browser
2. Click "Download All Icons"
3. Move the downloaded PNG files to this icons folder
4. Done!

## Alternative Methods

You can also create these icons in other ways:

### Option 1: Online Icon Generators

1. Visit [Favicon.io](https://favicon.io/favicon-generator/)
2. Create a simple icon with text or emoji
3. Download and resize to the required dimensions

### Option 2: Use an Image Editor

1. Open any image editor (Photoshop, GIMP, Paint.NET, etc.)
2. Create three new images with the dimensions above
3. Add your design (keep it simple - a letter, symbol, or simple graphic)
4. Save as PNG files with the exact names listed above

### Option 3: Use Placeholder Icons

For testing purposes, you can use simple colored squares:

1. Use any online image creator
2. Create solid color squares in the required sizes
3. Save as icon16.png, icon48.png, and icon128.png

## Design Suggestions

- Use a simple design that's recognizable at small sizes
- Consider using a download arrow or Google Drive-related symbol
- Keep colors consistent across all three sizes
- Make sure the icon works well on both light and dark backgrounds

## Quick Tip

The easiest option is to create a 128x128 icon and then resize it down to 48x48 and 16x16.
